# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) for all araCreate Group repositories.

## Brand

- Company: **araCreate Group** (lowercase 'a', capital 'C') — never "AraCreate" or "aracreate"
- Products follow their own capitalisation — e.g. **CephaBot** (capital C and B)

## Repo structure

All araCreate repos follow this standard layout:

```
project-name/
├── src/              # Main source — contents vary by project type
├── docs/             # Documentation
├── assets/           # Images, diagrams, brand, media
├── tests/            # Test suites and isolated prototypes
├── scripts/
│   └── motd          # ANSI Shadow project name + metadata
├── Makefile          # Unified entry point
├── CHANGELOG.md      # Auto-generated by semantic-release
├── LICENSE
└── README.md
```

### `src/` by project type

**Software (Next.js / web)**
```
src/
├── app/            # Next.js App Router routes
├── components/     # UI components
├── lib/            # Business logic, data access
├── types/          # TypeScript types
├── data/           # JSON / data files
└── public/         # Static assets
```

**Firmware — Zephyr**
```
src/
├── main.c
├── include/
├── drivers/
├── boards/
├── CMakeLists.txt
└── prj.conf
```

**Firmware — Bare-metal**
```
src/
├── main.c
├── hal/
├── drivers/
├── include/
└── lib/
```

**Hardware — KiCad**
```
src/
├── project.kicad_pro
├── schematic.kicad_sch
├── pcb.kicad_pcb
└── libraries/
fabrication/        # Gerbers, BOM, assembly files
```

## File headers

Every source file must start with:

**JavaScript / TypeScript:**
```ts
// SPDX-License-Identifier: LicenseRef-Proprietary
// Copyright (C) 2026, araCreate Group
// Author: Aravinth Panch <ara@aracreate.group>
// Description: PROJECT NAME: This file contains <what>
```

**Python:**
```python
#!/usr/bin/env python

# SPDX-License-Identifier: LicenseRef-Proprietary
# Copyright (C) 2026, araCreate Group
# Author: Aravinth Panch <ara@aracreate.group>
# Description: PROJECT NAME: This file contains <what>
```

**C / C++:**
```c
// SPDX-License-Identifier: LicenseRef-Proprietary
// Copyright (C) 2026, araCreate Group
// Author: Aravinth Panch <ara@aracreate.group>
// Description: PROJECT NAME: This file contains <what>
```

**JSON data files** — no comments, use `_meta` object instead:
```json
{
  "_meta": {
    "spdx": "LicenseRef-Proprietary",
    "copyright": "Copyright (C) 2026, araCreate Group",
    "author": "Aravinth Panch <ara@aracreate.group>",
    "description": "PROJECT NAME: This file contains <what> in JSON format",
    "version": "1.0.0"
  },
  "data": []
}
```

- Description format: `"PROJECT NAME: This file contains <what>"`
- `version` field: data files only, not source files

## Naming conventions

- **param-case** — file names, URLs, CSS classes, CLI flags, HTML attributes
- **snake_case** — JSON keys, JS/TS variables/properties, Python variables, C variables

## Makefile

Every repo has a `Makefile` at root. Standard targets:

```makefile
make install    # Install dependencies / tools
make setup      # Set up environment
make dev        # Run locally (software)
make build      # Build / compile
make test       # Run tests
make release    # Cut semantic release
make clean      # Remove build artefacts
```

`make help` (default target) displays `scripts/motd` followed by the target list.

## motd

`scripts/motd` uses **ANSI Shadow** font (via figlet) for the project name, followed by the metadata block:

```
# description = "PROJECT NAME"
# author      = "Aravinth Panch <ara@aracreate.group>"
# copyright   = "Copyright (C) 2026, araCreate Group"
# license     = "LicenseRef-Proprietary"
# version     = "0.0.1"
```

Generate with: `figlet -f "ANSI Shadow" "PROJECT NAME"`

## Git

- Never commit without explicit user approval
