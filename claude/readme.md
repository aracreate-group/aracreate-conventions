# CLAUDE

Conventions for working with Claude. Every Claude Code session starts from
them, through an import in the user's global `~/.claude/CLAUDE.md`:
`@<clone>/claude/claude-code-conventions.md`.

| Document | Covers | Read it when |
| --- | --- | --- |
| [claude-code-conventions](claude-code-conventions.md) | Ending a session, the todo list, replies, questions, links, asking before acting, live system changes, files, evidence, shell | **Always**, in every Claude Code session, VS Code or terminal |

claude.ai chats and scheduled cloud agents are not covered here.
