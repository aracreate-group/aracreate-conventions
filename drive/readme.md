# DRIVE

Google shared drive conventions for araCreate. Read the common one, then the
one for the kind of drive you are working in, before creating, renaming or
moving anything.

| Document | Covers | Read it when |
| --- | --- | --- |
| [conventions-drive](conventions-drive.md) | Naming, links, code, sharing and what stays out | **Always.** It holds in every shared drive. |
| [conventions-drive-projects](conventions-drive-projects.md) | Client folder shape, codes, what goes where, departments, lifecycle | Working in a projects drive |
| [conventions-drive-team](conventions-drive-team.md) | Person folders, org, projects and unsorted, shortcuts, leaving | Working in a team drive |

Organisation drives have their own structure and follow only the common
document.
