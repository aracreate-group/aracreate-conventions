# LOGS

The project log: one file per day the repo changes, `log-YYYY-MM-DD.md`, one
row each in the index below. A day with more than one effort carries them as
sections of the same file. Written once per push and not edited once pushed;
commit messages explain each commit, the log explains the day. The rules are
in [repo §5](https://github.com/aracreate-group/aracreate-conventions/blob/main/repo/readme.md#5-logs).

Start each log from [log-template.md](log-template.md). A session's handoff,
plans and drafts, and the local `todo.md`, live in `../wip/`, never here.
