# SOURCE

The project's own source — application code, firmware, or hardware design files.
The layout depends on the project type (see
[`src/` by project type](https://github.com/aracreate-group/aracreate-conventions/blob/main/repo/readme.md#21-src-by-project-type)).
Third-party code you do not maintain is vendored here as git submodules, not
edited in place.
