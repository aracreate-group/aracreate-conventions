# Publish logs, drive and Claude Code conventions

Work of 2026-10-08, committed 2026-10-08. The latest revision of the
conventions was copied into this repo, and the repo's own tooling, which no
convention needs, was removed. It went out in two pushes: everything up to the
removal of the wiki first, then the readme cleanup, the Claude Code
conventions and this log.

## Changed

- `git/`: the day's log is committed with each push.
- `git/`: GitLab conventions gain shared MRs for child tasks, `[tbd]` titles,
  `ACTIONS` kept apart from the MR's `OPEN`, closing by status,
  cross-project references and URL-encoded searches; examples use generic
  names.
- `repo/`: §5 Logs added; the template gains `logs/logs.md`,
  `logs/log-template.md`, `wip/`, and `.tmp/` in `.gitignore`.
- `drive/`: new, the shared drive conventions, common, projects drive and
  team drive.
- `claude/`: new, the Claude Code session conventions.
- Root: `Makefile`, `VERSION`, `scripts/motd` and `wiki/` removed, `.tmp`
  ignored, the README catalogue lists `drive/` and `claude/`, and `logs/`
  started.

## Decided

- The repo keeps no `Makefile`, `VERSION` or `motd` of its own: it ships
  documentation, and the template carries them for repos that need them.
- The toolchain notes left the published repo, as reference material rather
  than a convention.
- The zsh notes in the Claude Code conventions §10 are conditional, since not
  every reader's shell is zsh with `noclobber`.
- `logs/` sits at the root although the root is otherwise a folder per
  convention domain: repo §5 holds in every repo, this one included.
